# 字幕工作室 · Subtitle Review Studio

**在本机完成字幕初查，把有依据的意见交给 AI，把最终取舍留给人。**

A local-first subtitle review workbench for Windows: Whisper transcription, automatic CPU/GPU benchmarking, external AI handoff, human review, and traceable SRT delivery.

字幕工作室把音视频、SRT、剧本和识别证据放进同一个本地工作流。它适合批量剧集字幕校对、AI 字幕复核，以及需要保留修改依据和人工进度的团队。

## 下载安装

普通用户请到 [Releases](https://github.com/HeGrand/subtitle-review-studio/releases) 下载 Windows 便携版。GitHub 页面上的 **Code → Download ZIP 是源码，不包含运行环境或识别模型**。

- **已有旧版**：可只下载`update.zip`，关闭旧程序后覆盖到程序目录；不必重下模型/GPU，详见安装说明。
- **主程序包**：内含 Python、依赖、FFmpeg 和多语言识别模型，解压后可用 CPU 初查。
- **GPU 组件包（可选）**：NVIDIA 用户将它解压到主程序目录，合并 `.runtime` 文件夹，即可自动测速并启用 GPU。无需安装系统 CUDA。
- 发布附件附带 SHA-256 清单。请完整解压后双击 **字幕工作室.exe**，不要在压缩包内直接运行。

GPU 加速仍需要电脑已有兼容的 NVIDIA 显卡和驱动。没有可用 GPU 时自动使用 CPU。[详细安装说明](docs/INSTALL.md)

## v0.2：统一选择与真实路径拖放

Windows便携版现在默认打开桌面窗口。视频/SRT文件夹、模型目录、新建或打开项目路径可从资源管理器拖入，显示真实完整路径，包括Windows已连接且有权限的UNC共享盘。JSON和剧本拖到对应区域即可读取/导入，并显示来源。

桌面版使用 Windows 文件窗口，视频可以多选。浏览器版使用应用内文件浏览器，支持磁盘和共享盘路径。

## v0.3 剧本匹配生成字幕

首页有两个独立入口：**生成字幕**与**校对已有字幕**。旧项目继续按原方式打开，生成项目不需要已有 SRT。

生成流程：新建生成项目 → 添加音视频 → 选择原声语言 → 生成 → 听改 → 导出 SRT。可选导入整本剧本或为单集粘贴文稿，生成时会使用对应集数和语言的文稿匹配。桌面版通过 Windows 文件窗口选择文件或文件夹。每行字数和每条最长时长可设置，字幕最多两行，英文缩写使用直撇号，保留对应剧本的问号、破折号等标点。听改时可按波形点击或拖动选择拆分点，分别试听前后两段；可按识别时间建议分句，手动修改的文字不会被覆盖。也可与相邻字幕合并、共用一个切点或试听并采纳建议入点。疑点按优先级排列，交付页可直接定位待处理项。

规则提取支持分集标题、角色独立行的中英双语剧本，以及“角色：台词”格式。复杂排版可在“AI 接口设置”配置兼容聊天补全格式的接口地址、模型与 Key，然后主动提取本集；结果必须逐字回查原文，再由用户确认。测试连接会调用一次模型；不会自动调用外部服务，不上传视频或音轨。未配置 API 可继续使用规则与手动编辑。

生成以本地识别出的词及其时间为基础，独立匹配剧本片段以允许删改、调序和重复；有文稿时只输出定位到的台词。未匹配片段进入听改，当前版可导出，交付版须逐段确认不出字幕或补字幕。它不等同于已完成人工听证，尚不能保证超过剪映。特别短的对白、重叠人声、低声、配乐及中文词内字边界仍应听改。生成队列可单集重新匹配或清空字幕后修改文稿。旧版先归档，可在应用里对比并恢复。暂停后的已完成识别分段可继续复用，某集失败不阻断后续集数。

## 可以做什么

- **批量整理素材**：扫描分集视频/音频与 SRT，逐集处理缺失或多版本配对。
- **读取剧本**：支持 Word DOCX 正文及表格、UTF-8 文本、Markdown 和可提取文字的 PDF。
- **本地识别初查**：多语言 Whisper 识别、逐词时间戳、文字及入出点候选；暂停后保留已完成分段。
- **自动选择 CPU/GPU**：同一段音频、同样的解码设置，预热后各计时两次，选择实际更快且可用的设备；GPU 故障时保留分段并改用 CPU。
- **独立 AI 交接包**：导出字幕、资料、识别稿、疑点片段、稳定 ID、执行流程和回传模板，交给自己使用的外部 AI，再导回 JSON 意见。
- **清晰的审查分类**：区分文字未见具体问题、确定修正、具体人工疑点、草稿和真正未完成工作。
- **顺手的人工复核**：字幕前后局部波形、按空格播放/暂停、到字幕出点停止、多轮 AI 意见并列、通过或删除后自动选下一条。
- **批量取舍**：有证据的确定文字建议可批量采用；重复术语集中确认；独立称谓与姓名可预览合并。
- **保护人工进度**：保留原始字幕、稳定 ID、修改历史、草稿与人工通过状态，关键修改可撤销。
- **可追溯交付**：导出干净 SRT、审查记录或备份，不裁剪原媒体、不平移后续字幕。

## 推荐工作流

1. 新建独立项目，项目目录放在程序目录之外。
2. 导入音视频、SRT，按需添加剧本、人物名表和术语表。
3. 运行本地初查。全部集数完成后，可按弹窗前往 AI 交接页。
4. 导出 AI 包，让外部 AI 按包内 `README_先读我.md` 执行，再导入返回的 JSON。
5. 采用依据充分的确定修正，处理具体疑点、草稿和整组术语取舍。
6. 导出交付版；结束前在页面保存并关闭项目。

```mermaid
flowchart LR
    A[音视频 + SRT + 剧本] --> B[本地识别与初查]
    B --> C[独立 AI 交接包]
    C --> D[外部 AI 文字对照]
    D --> E[导回意见与人工复核]
    E --> F[干净 SRT 与审查记录]
```

**默认只审查 SRT 中已有的字幕。** 没有对应字幕的识别片段作为范围外记录，不要求补写，也不阻挡交付。已有字幕的具体疑点、未完成工作和未确认草稿仍须处理。

AI 没有直接听取音频的能力，不等于全部字幕都要转人工。已实际完成、没有具体问题的文字对照无需逐条人工点击通过；没有执行的工作也不能靠换标签当作已审。程序保留实际审查范围，不把文字对照冒充逐句听审。

## 加速与模型

便携版默认携带多语言 `large-v3-turbo` 模型。首次需要识别时检测电脑，用同一段最多 12 秒的音频比较 GPU/CPU 的预热后耗时；首次测速会多等待几十秒，之后复用本机结果。硬件、驱动、模型或运行组件变化会重新检测，素材页也可清除测速缓存。

一次本机参考测试：i7-13650HX / RTX 5070 12GB，同一段 164.49 秒音频，CPU 总耗时 **91.02 秒**，GPU 总耗时 **7.70 秒**，均包含新进程和模型加载，约 **11.8 倍**。这只是单集实测，不代表其他电脑或整部剧的速度。

CPU 使用 int8，GPU 使用 float16；模型及解码设置保持一致，数值精度可能带来识别差异。应用不会因此改写已有人工字幕。已有识别稿继续复用，不因升级强制重跑。[性能与验证范围](docs/PERFORMANCE.md)

## 从源码运行

主要面向 Windows 10/11 x64。建议 Python 3.12 或更新版本。

```powershell
git clone https://github.com/HeGrand/subtitle-review-studio.git
cd subtitle-review-studio
python -m pip install --target .runtime/deps -r requirements.txt
python scripts/build_launcher.py
.\字幕工作室.exe
```

也可双击 `准备环境.cmd` 自动准备组件；源码方式首次安装依赖和模型需要网络。已经完整解压的便携版不会执行这一下载流程。

源码目录不包含模型和 NVIDIA 二进制组件。准备本地模型及 GPU 组件、构建便携包的方法见 [BUILD.md](docs/BUILD.md)。

## 开发与测试

后端使用 Python 标准库 HTTP 服务，前端为原生 HTML/CSS/JavaScript。识别在可停止的独立子进程中运行，项目及证据保存在使用者选择的目录。

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
node --check web/app.js
```

浏览器测试、CPU/GPU 对照和便携验收入口见 [CONTRIBUTING.md](CONTRIBUTING.md)。测试使用合成字幕和临时项目，不需要任何真实剧集。

## 数据、范围与限制

- 服务只监听 `127.0.0.1`，程序不会自动上传素材；生成模式可主动调用用户配置的 AI 接口提取本集剧本，API Key 由 Windows 当前用户加密保存，不进入项目或导出包。
- 项目和媒体独立于程序。分享源码或发布包不需要附带剧本、视频、审核历史、最近项目或测速配置。
- 识别可能受口音、低声、配乐、短中文和混合语言影响。机器识别为空不代表没有对白。
- 时间边界、中文对白及关键含义冲突仍需要根据具体证据决定，生成时小幅音频校准会记录改动，较大的时间偏移只给建议；听改后可确认导出。
- Windows 便携版和真实 GPU 流程已在本机隔离目录验证，尚未在第二台完全干净的 Windows 电脑实测。
