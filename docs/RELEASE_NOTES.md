首次公开预览版：本地字幕初查、CPU/GPU 自动选路、外部 AI 交接、人工复核与可追溯 SRT 交付。

下载方式：

1. 下载并完整解压 `windows-x64.zip`，双击“启动字幕审查.cmd”。主程序包自带 Python、依赖、FFmpeg 和多语言模型，CPU 可直接使用。
2. NVIDIA 用户可选下载 `nvidia-gpu-addon.zip`，解压到**含启动入口的程序目录**，合并 `.runtime`。首次识别会实测 CPU/GPU，选择更快且可用的一方，故障回退 CPU。
3. 首次测速会增加几十秒等待，之后复用本机结果。新建项目请选择程序目录之外的文件夹。

源码压缩包不含运行环境或模型。完整使用说明见仓库 README；校验和见 `SHA256SUMS.txt`。

主程序和 GPU 组件按功能拆分，CPU 用户无需下载 GPU 部分。程序不自动上传素材、不调用付费 AI API；外部 AI 由使用者自行选择。

已有人工作业不因升级被批量通过、覆盖或重新识别。默认只审已有 SRT 字幕，没有对应字幕的识别记录不阻挡交付。

原创代码采用 MIT，第三方组件保留各自许可证。便携流程已在本机隔离目录验证，尚未在第二台完全干净的 Windows 电脑实测。性能数字和适用范围见 `docs/PERFORMANCE.md`。
