# 字幕工作室 v0.3.0

- 双入口支持文稿匹配、纯音频识别和已有字幕听改。
- Windows EXE 与炭黑对白图标，新增集数工作台、单集重跑、旧版对比与恢复。
- 支持句末断句、入点试听、相邻字幕共同切点和疑点优先级。
- 交付前可定位待处理项，文稿匹配项目直接导出 SRT。
- 可选配置 AI 接口，按需提取和复查；语音识别在本机运行。

下载 Windows x64 主程序包并完整解压，双击 **字幕工作室.exe**。主程序包含 Python、FFmpeg 和本地多语言识别模型。NVIDIA 组件为可选附件，解压后合并到主程序目录。已有便携版可用更新包，关闭应用后解压覆盖程序目录，继续使用原模型。

附件校验见 `SHA256SUMS.txt`。业务项目请选择程序目录之外的位置。
