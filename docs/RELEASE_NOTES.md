# 字幕工作室 v0.3.1

- 英文文稿匹配新增离线 WhisperX 词级对齐。先定位原台词，再按音频定入出点，保留原文标点。
- 无法可靠定位的文稿进入听改，显示原台词、识别和试听入口。可以导出当前 SRT，处理完疑点后可导出交付版。
- 修复 Windows 任务栏显示 Electron 默认图标、全角句点误断和拆分字幕越过片长的问题。

## 下载

1. 完整解压 `windows-x64.zip` 主程序包。
2. 需要英文 WhisperX 文稿匹配时，解压 `whisperx-en-addon.zip` 到包含 **字幕工作室.exe** 的主程序目录，合并 `.runtime`。它内含英文对齐模型。
3. 有兼容 NVIDIA 显卡时，可按同样方式合并 `nvidia-gpu-addon.zip`，启用本机 GPU 测速和识别加速。
4. 双击 **字幕工作室.exe**。已有项目从原目录打开，已有字幕可在生成页选择重新匹配。

`update.zip` 可用于旧便携版的程序文件更新。要使用本发布的 WhisperX 组件，请安装配套的 v0.3.1 主程序和组件包。附件校验见 `SHA256SUMS.txt` 及更新包的 SHA-256 文件。
