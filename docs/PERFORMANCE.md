# 性能和验证范围

## 已有的单机参考数据

机器：Intel Core i7-13650HX、NVIDIA RTX 5070 12GB。模型：多语言 large-v3-turbo。相同 164.490 秒音频，两个新的独立进程顺序运行，没有复用已有识别分段。

- CPU int8：总耗时 91.022 秒，其中识别循环 85.720 秒。
- GPU float16：总耗时 7.700 秒，其中识别循环 3.636 秒。
- 包含模型加载的总耗时约加速 11.82 倍。

两边保持 beam_size=5、逐词时间戳、30 秒分段、自动语言识别、VAD 关闭和 condition_on_previous_text=False。CPU/GPU 数值精度不同，分段数和文字可能不同，不把它们宣称为逐字一致的结果。

以上只是这台机器、这集音频当时的实测，不能外推到所有剧集、显卡或电脑。构建版本的组件清单、驱动、负载和音频内容都会影响速度。

## 自动测速

第一次需要本地识别时，用同一段最多 12 秒的音频分别加载 GPU/CPU，预热一次后计时两次，使用中位耗时选路。GPU 可用且不慢于 CPU 时优先 GPU；CPU 更快时用 CPU；不支持或故障时用 CPU。没有完成 CPU 测速时不会声称已经证明 GPU 更快。

测速会额外消耗几十秒，不能把首次测速总耗时当成稳定识别速度。按机器、驱动、模型和运行组件缓存结果，后续识别复用；素材页可清除后重新检测。

## 已验证的行为

- 单元检查覆盖 GPU/CPU 速度比较、平手、缺 GPU、GPU 原生错误、CPU 测速失败、暂停、驱动变化、缓存复用、保留分段后 CPU 继续，以及原有人工处理记录保留。
- 真实本地浏览器检查覆盖播放边界、空格播放/暂停、自动下一条、意见呈现、范围外批量收起、术语组确认、完成弹窗和测速缓存清除。
- 独立便携目录在屏蔽系统 Python、用户模型缓存和其他软件 DLL 路径后，完成自动测速和真实 GPU 初查，已人工通过的字幕逐字段保持不变。
- 发布压缩包实际解压，并检查文件大小和 SHA-256，不包含业务项目、最近记录或个人测速配置。

尚未在第二台完全干净的 Windows 电脑上验收，也没有把上述速度测试当作字幕准确率评测。新版本是否通过持续集成，以仓库实际 workflow 结果为准。
