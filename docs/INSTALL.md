# 安装与首次使用

## Windows 便携版

在 Releases 下载主程序包，完整解压到可写目录。打开解压后的文件夹，双击 **字幕工作室.exe**。桌面窗口支持从资源管理器拖入文件和文件夹，关闭时会先保存草稿、暂停任务并关闭项目。

主程序包包含运行环境、音频组件和多语言识别模型，不需要自行安装 Python。CPU 可直接使用。

### 英文文稿匹配

下载与主程序同版本的 `whisperx-en-addon.zip`，解压到包含 **字幕工作室.exe** 的目录，合并 `.runtime`。该组件自带英文词级对齐模型，可离线使用。已有字幕可在生成页选择重新匹配。

### NVIDIA GPU 加速

另下载可选 GPU 组件包。**把它解压到已经包含字幕工作室.exe 的程序目录**，合并 `.runtime`，不要另套一层同名目录。

最终应有这样的结构：

```text
字幕工作室_Windows便携版/
  字幕工作室.exe
  app/
  web/
  .runtime/
    python/
    deps/
    models/
    gpu/
```

首次需要识别时，程序会检测 NVIDIA 显卡，用同一短段音频实际比较 CPU/GPU 速度，选择更快且能正常运行的一方。首次会增加几十秒等待；后续复用结果，素材页可点击“重新检测速度”。

驱动由电脑已有环境提供。没有兼容显卡、驱动或组件时自动使用 CPU；运行中 GPU 出错也会保留已完成分段并改用 CPU。

## 更新旧便携版

只更新程序文件时，下载 `update.zip` 及对应校验文件。保存并关闭旧程序后，将更新包解压到原程序目录并允许覆盖，再双击 **字幕工作室.exe**。使用新版 WhisperX 时，请安装配套的主程序和组件。已有项目从原目录打开。

## 新建项目

1. 在页面新建项目，选择**程序目录之外的空目录**。
2. 导入音视频和 SRT；检查分集配对。
3. 按需导入 DOCX、文本或 PDF 剧本、人物名表和术语表。
4. 运行初查。全集完成后可跳转 AI 交接页。
5. 导出 AI 包，用自己的外部 AI 完成文字对照，再导入返回 JSON。
6. 处理具体疑点、草稿和术语取舍后导出交付版。

结束时先在页面“保存并关闭”项目，再关闭启动窗口。下次打开原项目可继续进度。分享给同事请使用原始发布压缩包，个人使用后的程序目录可能已经有自己的最近项目和测速配置。

## 源码方式

源码需要另准备 Python、依赖和模型：

```powershell
python -m pip install --target .runtime/deps -r requirements.txt
.\启动字幕审查.cmd
```

也可双击 `准备环境.cmd`。首次自动准备或下载模型需要网络，完成后本地处理不上传素材。

源码 GPU 运行组件可通过 `scripts/prepare_gpu.ps1` 准备。准备过程联网下载 NVIDIA 的 Windows 软件包到本项目 `.runtime/gpu`，不修改系统 CUDA 或驱动；详情见 [BUILD.md](BUILD.md)。
